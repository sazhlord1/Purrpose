## 2. Executive summary

Purrpose is a commitment app where a cartoon cat watches your pacts; failing a strict pact donates real cat food to shelters.
It is a pnpm monorepo (React/Vite web, Fastify/Prisma server, SVG cats package, shared zod package, Capacitor Android) that
ships **two editions from `main`**:

- **Global** (English + Persian): web on Cloudflare Workers, API on Render (INFERRED), DB on Supabase, Stripe, Google sign-in.
- **Iranian — پرپس**: one Liara Docker container serves API + Persian web app (`app.purrpose.ir`) + Persian landing
  (`purrpose.ir`), Liara Postgres, phone + SMS login (IPPanel/Artapayamak), Enamad seal, Persian legal pages. Designed to work
  during international internet shutdowns.

The Iranian edition is live as a website. Android **v1.0** (edition `ir`) was built but **not published**. The owner's next
goal is publishing on **Cafe Bazaar with in-app billing** (food + PURR packs). That billing is **not implemented yet** and is
the main blocker. Before touching anything: every push to `main` deploys production; schema changes need Supabase SQL first;
the repo is public (no secrets).

## 10. Critical implementation notes
- **Every push to main deploys production** (Liara, Cloudflare, likely Render). Never push red code; check CI after each push.
- **Schema change order:** write Prisma migration + `infra/supabase_upgrade_v11.sql`; owner runs SQL on Supabase; only then push.
  Liara applies migrations automatically at container start (`Dockerfile` CMD) — a broken migration takes the Iranian site down.
- **Settlement must stay exactly-once** (`settleDue` with `FOR UPDATE SKIP LOCKED`; appeal/decision use row locks). Any new
  crediting path (Bazaar) must be idempotent per purchase token.
- **AppEvent JSON filters** (`payload: { path: ['commitmentId'], equals }`) are used for appeals and consent — keep payload keys stable.
- **Speech bubble rendering:** keep one `<text>` per line (Android WebView bidi bug). Bubble is drawn by `CatScene`, reported by `LivingCat.onBubble`.
- **Generated landing:** change `scripts/sync-landing-ir.mjs` / `landing-ir-seo.mjs` / `landing-ir-faq.mjs`, not only `apps/landing-ir/index.html`.
- **Phone numbers:** must be `09` + 9 digits (11 total); Persian digits accepted and normalized (`phoneSchema`).
- **IPPanel:** sender `SMS_FROM` normalized to `+98…`, pattern variable `SMS_CODE_PARAM=code`.
- **Package name / keystore:** never change `space.purrpose.app`; never lose the keystore (GitHub secrets).
- **Iranian edition must not reference external hosts** (CSP `connect-src 'self'` on Liara).
- **Admin dev pages** `/lab`, `/cats`, `/design` are admin-only in production; `/api/v1/dev/*` only with `NODE_ENV=development`
  (default is production — keep it that way).
